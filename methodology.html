1. 무엇을 측정하나

자체 점수·순위·등급·평가는 일절 산출하지 않는다. 측정 대상은 단지별 국토부 공공 실거래 사실 통계: 동일평형(전용 ±3.5㎡)·이름매칭으로 묶은 12개월 실거래에서 ① 중위(억)와 표본수 n, ② 분포(P25–중위–P75 협상 레인지), ③ 추세(최근 3개월 중위 vs 직전 9개월 중위의 방향·변화%), ④ 52주 위치(최근 3개월 체결 중위가 12개월(52주) 실거래 최저~최고 레인지에서 차지하는 위치 % — 헤드라인 중위와 기준점이 다름). 모두 관측된 사실값이다. 세대수 100세대 미만 단지와 환금성 우려가 큰 일부 corridor 단지는 실거래 단지 표에서 게재 전 제외한다. 이름매칭은 2026-09-05부터 단지명 canonical 완전일치만 적용한다(부분일치·접두 매칭 없음).

별도로 서울 25개 구의 법정동별 아파트 목록을 매일 관측해 네이버 표시 매매·전세·월세·단기임대 건수를 소재구별로 합산한다. 이 값은 발행 단지 수나 RTMS 거래 표본과 독립이며, 같은 출처·범위·방법의 정확히 1일·7일 전 완전 관측끼리만 증감을 계산한다. 표시 건수는 한 주택 수나 수요를 뜻하지 않고 중개사 중복 노출이 있을 수 있다.

단지 생활 맥락은 최근접 학교·학원 정보, SRTM30m 중심±150m 표고 기반 경사 근사, 외부 커뮤니티 후기의 표본수·긍정/주의 테마로 제공한다. 학교는 배정학교를 뜻하지 않고, 경사는 실제 보행 경사가 아니며, 후기 원문·평점은 공개하거나 순위에 쓰지 않는다. 미수집·오래됨·항목별 확인일 없음 상태를 함께 표시한다. 구·단지 페이지의 주민 관찰 제보는 공개 GitHub Issue Form으로 받으며, 검토 전에는 외부 후기 표본이나 가격·점수·순위에 자동 합산하지 않는다.

2. 데이터 출처

실거래 = 국토교통부 RTMS 공공데이터(12개월 동일평형 중위, 이상치 −40% 컷), 매일 자동 재수집. 세대수·준공연도·전용면적·유형은 공개 단지정보다. 단지는 실명으로 게재한다(공공 실거래의 named 재이용은 공공데이터법상 합법). 가격 표에는 네이버·KB 등 사설 시세를 쓰지 않고 국토부 공공 실거래 중위(억)만 표기한다. 매물 노출 건수는 네이버부동산 법정동별 단지 목록, 경사는 OpenTopoData SRTM30m, 학교·학원 근접성은 수집 당시 공개 검색 결과, 후기 테마는 연결된 외부 커뮤니티 집계 파일을 출처로 하며 각 화면에 관측·확인 상태를 별도로 표시한다. K-apt 난방·주차는 단지코드·소재구·이름·세대수·준공연도를 교차검증하고 지상·지하 주차대수가 모두 있을 때만 세대당 주차를 계산한다.

3. 신뢰 규율

모든 집계는 결정론 파이프라인(LLM 재계산 0)에서 나온다. 가격·거래값은 국토부 실거래 F(사실)이고 표본수 n을 동반한다. 매물·학교·지형·후기는 서로 다른 근거를 섞지 않고 출처·관측시각·한계 또는 미수집 상태를 동반한다. 각 포스트에 머신리더블 provenance(claims.jsonl, 1행 1주장)와 JSON-LD Dataset(variableMeasured)이 동봉된다. 동일 입력 → 동일 산출이 회귀 테스트로 고정되고, 생성 전 커버리지·위생 게이트가 공백·중복을 차단한다.

4. 한계 (정직 고지)

표본이 적은 단지는 중위·분포가 불안정해 분포·52주 위치를 표시하지 않을 수 있다(표본 부족 구간은 — 처리). 추세는 과거 중위 비교(사실)일 뿐 미래 전망이 아니다. 발견 커버리지는 전수가 아니며, 데이터는 기준일 시점이다. 본 사이트는 개인 연구·정보 공유로 투자자문·매수권유가 아니다.
